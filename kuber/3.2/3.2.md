### Задание 1. Установить кластер k8s с 1 master node

1. Подготовка работы кластера из 5 нод: 1 мастер и 4 рабочие ноды.
2. В качестве CRI — containerd.
3. Запуск etcd производить на мастере.
4. Способ установки выбрать самостоятельно.

  > <h3>выбрал способ установки с помощью kubeadm.<h3>

### 1. Предварительная настройка узлов
#### 1.1. автозагрузка модулей ядра
```sh
# Настройка автозагрузки и запуск модулей ядра br_netfilter и overlay
[user@localhost ~]$ cat <<EOF | sudo tee /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF

[user@localhost ~]$ modprobe overlay
[user@localhost ~]$ modprobe br_netfilter

```

```sh
# проверка
[user@localhost ~]$ lsmod | grep br_netfilter
br_netfilter           36864  0
bridge                323584  1 br_netfilter

[user@localhost ~]$ lsmod | grep overlay
overlay               167936  0

```

#### 1.2. отключение swap
```sh

[user@localhost ~]$ sudo swapoff -a
[user@localhost ~]$ sudo sed -i '/ swap / s/^/#/' /etc/fstab
## Ожидаемый вывод команды – пустой. Она ничего не должна отобразить.
[user@localhost ~]$ sudo swapon -s

```

#### 1.3. Сетевые настройки (на примере node1)
##### 1.3.1. настроить статические адреса на свободном интерфейсе
```sh

[user@localhost ~]$ sudo nmcli con mod enp0s9 ipv4.addresses "172.30.120.201/24" ipv4.method manual
[user@localhost ~]$ sudo nmcli con up enp0s9
Connection successfully activated (D-Bus active path: /org/freedesktop/NetworkManager/ActiveConnection/19)

```
##### 1.3.2. настройка имён/адресов хостов (не будем настраивать dns сервер)
```sh

[user@localhost ~]$ cat <<EOF | sudo tee /etc/hosts
127.0.0.1       localhost

# The following lines are desirable for IPv6 capable hosts
::1     localhost ip6-localhost ip6-loopback
ff02::1 ip6-allnodes
ff02::2 ip6-allrouters

# Cluster nodes
172.30.120.201 node1.internal
172.30.120.202 node2.internal
172.30.120.203 node3.internal
172.30.120.204 node4.internal
172.30.120.205 node5.internal
EOF

```

```sh
# назначаем имя узлу
[user@localhost ~]$ sudo hostnamectl set-hostname node1.internal
```

##### 1.3.3. разрешаем пересылку пакетов
```sh

# Включаем forward пакетов:
[user@node1 ~]$ echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward
[user@node1 ~]$ sudo sed -i s/'^#net.ipv4.ip_forward=1'/'net.ipv4.ip_forward=1'/g /etc/sysctl.conf
[user@node1 ~]$ sysctl -p

```
```sh
# Разрешение маршрутизации IP-трафика
[user@node1 ~]$ echo -e "net.bridge.bridge-nf-call-ip6tables = 1\nnet.bridge.bridge-nf-call-iptables = 1\nnet.ipv4.ip_forward = 1" | sudo tee /etc/sysctl.d/10-k8s.conf
[user@node1 ~]$ sudo sysctl -f /etc/sysctl.d/10-k8s.conf

#проверка
[user@node1 ~]$ sysctl net.bridge.bridge-nf-call-iptables net.bridge.bridge-nf-call-ip6tables net.ipv4.ip_forward
net.bridge.bridge-nf-call-iptables = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward = 1

```
##### 1.4. Настройка SELINUX permissive
```sh

[user@node1 ~]$ sudo setenforce 0
[user@node1 ~]$ sudo sed -i 's/^SELINUX=enforcing$/SELINUX=permissive/' /etc/selinux/config

```

##### 1.5. настройка firewalld
```sh
[user@node1 ~]$ sudo firewall-cmd --add-port=6443/tcp --add-port=10250/tcp
success
[user@node1 ~]$ sudo firewall-cmd --add-port=6443/udp --add-port=10250/udp
success
```

### 2. Устанавливаем container runtime
#### 2.1. установка containerd в качестве container runtime
##### 2.1.1. установка бинарников containerd из github
```sh

[user@node1 ~]$ mkdir /tmp/containerd \
&& wget https://github.com/containerd/containerd/releases/download/v2.2.1/containerd-2.2.1-linux-amd64.tar.gz -O /tmp/containerd/containerd-2.2.1-linux-amd64.tar.gz \
&& cd /tmp/containerd && tar xvf containerd-2.2.1-linux-amd64.tar.gz
bin/
bin/containerd-stress
bin/containerd
bin/ctr
bin/containerd-shim-runc-v2

```
```sh

[user@node1 containerd]$ sudo systemctl stop containerd
[user@node1 containerd]$ cd bin
[user@node1 bin]$ yes | sudo cp -rf * /usr/bin
```
##### 2.1.2. Конфигурируем containerd
```sh

# Создание конфигурации по умолчанию для containerd
[user@node1 bin]$ sudo mkdir /etc/containerd/
[user@node1 bin]$ containerd config default | sudo tee /etc/containerd/config.toml >/dev/null

# Конфигурируем cgroup driver
[user@node1 bin]$ sudo sed -i 's/SystemdCgroup \= false/SystemdCgroup \= true/g' /etc/containerd/config.toml

```
##### 2.1.3. Устанавливаем службу containerd
```sh

# Установка systemd сервиса для containerd
[user@node1 bin]$ wget https://raw.githubusercontent.com/containerd/containerd/main/containerd.service
[user@node1 bin]$ sudo mv containerd.service /etc/systemd/system/

```

#### 2.2. Устанавливаем runc
#### 2.2.1. Устанавливаем runc из github
```sh
# Установка компонента runc
[user@node1 bin]$ wget -q https://github.com/opencontainers/runc/releases/download/v1.4.0/runc.amd64
[user@node1 bin]$ sudo install -m 755 runc.amd64 /usr/local/sbin/runc
[user@node1 bin]$ rm runc.amd64

```
#### Перезапуск сервисов и проверка
```sh
# Запуск сервиса containerd
[user@node1 bin]$ sudo systemctl daemon-reload
[user@node1 bin]$ sudo systemctl enable --now containerd

[user@node1 bin]$ sudo systemctl start containerd
[user@node1 bin]$ containerd --version
containerd github.com/containerd/containerd/v2 v2.2.1 dea7da592f5d1d2b7755e3a161be07f43fad8f75

```

### 3. Установка kubeadm, kubelet и kubectl
##### 3.1. Добавляем репозиторий Kubernetes yum repository.
```sh

[user@node1 ~]$ cat <<EOF | sudo tee /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://pkgs.k8s.io/core:/stable:/v1.35/rpm/
enabled=1
gpgcheck=1
gpgkey=https://pkgs.k8s.io/core:/stable:/v1.35/rpm/repodata/repomd.xml.key
exclude=kubelet kubeadm kubectl cri-tools kubernetes-cni
EOF

```

#### 3.2. Устанавливаем kubelet, kubeadm и kubectl
##### 3.2.1. установка пакетов из репозитория
```sh
[user@node1 ~]$ sudo dnf install -y --disablerepo=* --enablerepo=kubernetes kubelet kubeadm kubectl --setopt=disable_excludes=kubernetes

#####
```

##### 3.2.2. настройка crictl
```sh
# Настройка конфигурации crictl
[user@node1 ~]$ cat << _EOF | sudo tee /etc/crictl.yaml
runtime-endpoint: unix:///var/run/containerd/containerd.sock
_EOF

```
